# Verifying wiki updates in the browser pane

Read `docs/agents/verifying-the-ui.md` first for the general pane recipes.

- **Show a wiki update without changing anything: patch `fetch` in the page.** Through `javascript_tool`, wrap `window.fetch` so a request to `consolegameswiki.com/mediawiki/api.php` runs the real fetch, edits `body.parse.text` (remove, rename or re-level a table row) and adds 1 to `body.parse.revid`, then returns `new Response(JSON.stringify(body))`. In the same script click the footer's update button and the dialog's Update; the preview then lists the edits. A reload removes the patch.
  - Match a fragment of a cell, not a whole sentence: links split the Information text (`Unlocks in the <a>Main Scenario Quest</a>.`). Change the unlock name to a new slug (punctuation alone keeps the ID, so it shows as Changed, not New and Removed).
  - Wrap `window.fetch` again to layer another edit. Click the dialog's Update by coordinate or ref (`find "Update"` misses it), then wait about 8 seconds for the live fetch.
  - Applying an update stores the new page. Afterwards remove `contentUnlockLog.content`, `.newEntries`, `.declinedMatches`, `.lastUpdateCheck`, `.dismissedRevision` and `.offeredUpdate` and delete the status keys you seeded, or the next run says "up to date".
- **Show the automatic update notice with an older device copy, not a patched `fetch`.** The check runs as the app opens, so a patch made after load is too late and a reload drops it. In one `javascript_tool` call: `const b = (await import('/src/content/bundled-content.json')).default`, deep-copy it, lower `revisionId` by 2, `shift()` an entry off `sections[0].entries`, remove `contentUnlockLog.lastUpdateCheck`, `.dismissedRevision` and `.offeredUpdate`, and store the copy as `contentUnlockLog.content`. Then `navigate` to the app: the bundle is newer, so the notice offers it with Review and Dismiss. Review lists the removed entry under New and leaves the stored revision unchanged; Dismiss writes `contentUnlockLog.dismissedRevision` and the notice stays hidden after a reload.
